# Edge Case & Fallback Matrix

| Edge Case | Scenario | Vulnerability | System Mitigation Strategy |
| :--- | :--- | :--- | :--- |
| **EC-01: Zero Memory Anchors** | User inputs extremely vague query e.g., *"that picture from somewhere"* | Hallucination / Over-retrieval | Detect anchor score < 0.3. Trigger **Guided Clarification Mode**: Ask up to 2 structured questions (e.g., "Was it indoors or outdoors?", "Approximate year range?"). |
| **EC-02: Contradictory Clues** | User says *"Beach photo taken in winter in Delhi"* (Delhi has no beach) | Zero search results | RAG agent relaxes strict spatial/temporal constraints and alerts user: *"Delhi doesn't have a coastline, but I found beach photos from your Goa trip around that winter."* |
| **EC-03: Corrupted/Missing Metadata** | Photo has no geotag or EXIF date | Indexed search bypasses item | Vector store utilizes Vision API tag descriptions & OCR text instead of relying solely on EXIF metadata fields. |
| **EC-04: Conflicting Multi-Asset Query** | CSV contains multiple similar photos matching ambiguous memory | Overwhelmed user | RAG bot generates a **Clustered Summary Response** with direct thumbnail preview links & confidence scores (e.g., *"Found 3 candidate photos from July 2024"*). |
| **EC-05: Non-English/Mixed Language Input** | User searches in Hinglish/Code-switched text (e.g., *"dawai ki photo jo pichle saal li thi"*) | Keyword search failure | Embedding model handles cross-lingual semantic mapping automatically; prompt translates episodic intent to structured filters. |
